# FinPulse: сценарий технической демонстрации

Цель: за 6–8 минут показать продуктовый результат и инженерный подход, не завися от нестабильности RSS или внешнего LLM.

## До начала

```bash
docker compose up -d
docker compose ps
```

Откройте `http://localhost:3000`, `http://localhost:3000/api/docs` и заранее подготовьте терминал в корне проекта. Не показывайте `.env` и токены.

## Маршрут

1. **Проблема — 30 секунд.** «FinPulse собирает новости рынка РФ, показывает факты, риски и возможное влияние. Это не инвестиционная рекомендация».
2. **Публичный продукт — 90 секунд.** На главной перейти в публичную ленту и на страницу MOEX. Показать фильтр новостей и карточки/индикаторы. Если источник временно недоступен, показать корректное empty/fallback состояние как намеренную деградацию, а не ошибку.
3. **Персональный контур — 90 секунд.** Войти заранее подготовленным обычным пользователем, открыть профиль и показать параметры горизонта, риска, тикеров и секторов. Чат демонстрировать только при готовой локальной Ollama; иначе объяснить HTTP 503 как контролируемое поведение и перейти к тесту этого сценария.
4. **Архитектура — 60 секунд.** Открыть [architecture.md](architecture.md): React → FastAPI → use cases → PostgreSQL и изолированные RSS/MOEX/GigaChat/Ollama integrations с fallback.
5. **Доказательство качества — 90 секунд.** Показать результаты команд:

   ```bash
   docker compose exec backend pytest
   cd frontend && npm run check
   ```

   Указать: 69 backend tests, 9 frontend unit/integration tests, 3 Playwright e2e. Открыть [ci-cd.md](ci-cd.md) и [PORTFOLIO_READINESS_REPORT.md](PORTFOLIO_READINESS_REPORT.md).
6. **AI workflow и границы — 60 секунд.** Открыть [AI_ENGINEERING_CASE.md](AI_ENGINEERING_CASE.md). Сказать, что агент используется для декомпозиции, реализации и review, но изменения принимаются только после проверки. Назвать ограничения: migrations, refresh-token storage, localStorage JWT и backlog типизации.

## Что не заявлять

- Не называть продукт production-ready, не обещать SLA и не выдавать AI-ответы за инвестиционный совет.
- Не говорить, что GitHub Actions уже прошёл, пока нет URL конкретного run.
- Не демонстрировать реальные секреты, `.env`, персональные данные или credentials.

## Резервный план

Если интернет, RSS, MOEX или Ollama недоступны, основная ценность demo сохраняется: UI states, fallback-контракты, Swagger, Docker health, тесты, CI и архитектурная документация работают локально. Это стоит проговорить как design decision, а не оправдание.
